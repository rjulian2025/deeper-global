## Coding agent guidance

- Apply the AI Search + SEO Content Standard in `docs/AI-SEO-CONTENT-STANDARD.md` to every content type.
- Treat answer pages as Article with QAPage/Question/Answer when Q&A is visibly present.
- Never add reviews/ratings/stats that are not present, and never include personal phone numbers.
- Robots must explicitly allow major AI crawlers and reference the sitemap.
- Keep llms.txt and llms-full.txt generated at build from the published-content list only.
- Add or update schema, llms entries, and tests when introducing a new content type.
