API terms

Developer preview terms for Deeper API.

Deeper API is public educational content infrastructure for retrieval, citation, topic mapping, and developer evaluation. It is not a clinical, diagnostic, crisis, emergency, or care-delivery system.

Permitted use

You may use public preview endpoints for evaluation, prototypes, search, retrieval, citation, and non-diagnostic educational summaries that preserve Deeper Global attribution and canonical URLs.

Prohibited use

Do not use Deeper API to diagnose, treat, triage emergencies, replace professional care, imply a therapeutic relationship, remove crisis-routing language, or market a downstream product as clinical decision support.

Attribution

When displaying or summarizing answer content, cite the canonical answer URL and preserve reviewer, source, and educational-boundary metadata when available.

Commercial access

Public endpoints are a developer preview. Bulk use, redistribution, paid products, custom feeds, private support, or higher rate limits require separate commercial terms from Deeper Global.

Rate limits

Public preview endpoints may enforce request limits and return 429 with rate-limit headers. Clients should cache responsibly and retry only after the reset time.

No warranty

Deeper API is provided as-is during developer preview. Endpoint shape, availability, limits, and commercial terms may change before general availability.
