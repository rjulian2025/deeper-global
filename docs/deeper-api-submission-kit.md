## 100-word description

Deeper API is a developer-preview content API from Deeper Global. It exposes reviewed, evidence-informed mental health answer metadata for AI agents, search products, chatbot builders, care-navigation tools, and research workflows. The API includes canonical answer URLs, titles, summaries, extracts, topic categories, source references, review metadata, risk classes, and agent-readable usage boundaries. It is built for educational retrieval, citation, topic mapping, and responsible AI content enrichment. Deeper API is not a diagnosis, therapy, crisis, or treatment API; products using it should preserve the educational boundary and route urgent situations to appropriate support.

## Long description

Deeper API is structured mental health content infrastructure for the agentic web. It packages Deeper Global's reviewed mental health answer corpus into machine-readable indexes that AI agents, developer products, search systems, and knowledge tools can retrieve safely.

The developer preview includes an answer index, topic/entity index, priority index, llms.txt, agents.txt, and OpenAPI specification. Each answer record can include canonical URL, title, original question, topic, summary, extract, risk class, review tier, review status, reviewer attribution, source references, and freshness metadata.

The API is designed for products that need reliable educational mental health content without pretending to provide clinical care: AI copilots, therapy-adjacent apps, care-navigation research, mental health search, knowledge graphs, and agent workflows that need citation-ready answer metadata.

Deeper API is educational only. It is not a substitute for diagnosis, treatment, therapy, crisis support, or emergency services.

## Example use cases

- AI search engine retrieves mental health answer summaries with canonical citations.
- Agent classifies a user's broad concern into Deeper topic entities without generating clinical diagnosis.
- Care-navigation prototype links users to educational answers before suggesting professional support.
- Content workflow identifies high-risk mental health pages that need stronger review or freshness checks.
- Chatbot adds a clear educational boundary and routes crisis language away from generic answer retrieval.

## Safety language

Deeper API provides educational mental health information only. It does not diagnose, treat, replace therapy, or provide emergency support. For crisis, self-harm, overdose, violence, or immediate danger, products using Deeper API should route users to emergency services or crisis resources.
