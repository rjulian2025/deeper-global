Design evolution · topic directory

Taxonomy enrichment concepts

Make the directory feel like a mental health knowledge map — richer and more comprehensive without counts, pills, or cards.

Recommendation: Concept C + “People often ask”

A one-line descriptor orients each territory. Three curated questions beneath give concrete entry points — rewritten as natural language, not article titles — without competing with primary topic links.

Baseline — topics only

Clean but sparse. Categories float without context or depth cues.

A — Category descriptors

Territory is clearer. Feels more like a map, though depth is still implied not shown.

B — Related questions only

Strong discoverability, but categories alone can feel thin without framing.

C — Hybrid (descriptor + questions)

Production

Descriptor orients; three curated questions prove depth. Best knowledge-map feel without clutter.

Question label alternatives (Hybrid C)

Same three curated questions per category — only the section label changes. “People often ask” reads most editorial; “Common questions” is direct; “Frequently explored” is slightly more neutral.
